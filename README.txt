SHIFTPAY TRACKER — PWA STARTER

Files:
- index.html: app
- manifest.webmanifest: Home Screen app metadata
- sw.js: basic offline caching
- icons/: app icons

IMPORTANT:
1. This is a starter prototype. Test it before relying on it for payroll.
2. Estimated net pay uses flat percentages and is not an official Canadian payroll calculation.
3. Overtime multiplier is saved as a workplace setting but is not yet applied to pay calculations.
4. Data is stored in this browser on this device. Use Export backup regularly; no iCloud sync is included.
5. The app must be hosted on HTTPS for reliable PWA installation and service-worker/offline support. Opening index.html directly from a file will not enable PWA installation.
6. Keep the entire folder structure when uploading.

Suggested next step:
Upload these files to a static HTTPS host (for example GitHub Pages) from your Windows laptop, then open the HTTPS link in Safari on your iPhone and choose Share > Add to Home Screen.
